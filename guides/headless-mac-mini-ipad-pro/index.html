Headless Mac mini with an iPad Pro: the setup guide

A Mac mini is a wonderful computer to not look at. Small, silent, always on, and cheap to run. With Mimac, your iPad Pro becomes the display it never had, at the iPad's exact resolution and 120 fps, with your Magic Keyboard doing the typing. About twenty minutes, one time.

What you need

  • A Mac mini or Mac Studio with Apple silicon running macOS 15 or later. Intel Macs are not supported.
  • An iPad with an M-series chip on iPadOS 26 or later, ideally an iPad Pro with a Magic Keyboard. Any trackpad and keyboard will do.
  • Both devices on the same Wi-Fi or Ethernet network for the setup.
  • A monitor, or another Mac, for the very first setup. After this you will never need it again.

Steps

  1. Do the first setup with a display, once.

    macOS needs a person to click through Setup Assistant, create the user account and approve two permissions for Mimac Connect. Plug in any monitor for this, or, if the Mac is already set up, turn on Screen Sharing in System Settings → General → Sharing and do the rest from another Mac. Leaving Screen Sharing on is a good idea anyway: it is your fallback if a future macOS update ever resets a permission.

  2. Install Mimac Connect.

    Download it from mimac.ai/mac and run the installer. Tick Start before login: it installs a small system agent that owns Mimac's display from the moment the login window appears, so a restarted Mac is reachable before anyone has logged in. Leave Mimac Microphone ticked if you use dictation. Both ask for your administrator password.

  3. Grant Screen Recording and Accessibility.

    Mimac Connect appears in the menu bar and asks for both. Screen Recording lets it capture the display; Accessibility lets it move the pointer and type. Approve them in System Settings → Privacy & Security. Without Accessibility you will see the Mac but not be able to control it.

  4. Decide about FileVault.

    With FileVault on, a restarted Mac stops at a pre-boot unlock screen before macOS is running. Nothing can reach it there, not Mimac, not Screen Sharing, not anything, until someone types the password locally. If the Mac lives in your home or a locked office, turn FileVault off in System Settings → Privacy & Security and enjoy unattended restarts. If it lives somewhere you do not control, keep FileVault on and only restart when you can be there. There is no third option, and anyone who tells you otherwise is selling something.

  5. Keep the Mac awake and reachable.

    In System Settings → Energy: turn on Prevent automatic sleeping when the display is off, Wake for network access, and Start up automatically after a power failure. A headless Mac that falls asleep is a Mac you drive across town to press a key on.

  6. Pair from the iPad.

    Open Mimac on the iPad. Macs running Mimac Connect on the same network appear by name; tap yours. Click the Mimac icon in the Mac's menu bar to read the six-digit pairing code and type it on the iPad. That is the last time you will type it: both devices keep a key in their Keychain from now on, and every session is end-to-end encrypted with keys derived from it.

  7. Unplug the monitor.

    Mimac creates a virtual display at your iPad's exact resolution, 2752×2064 on the 13-inch iPad Pro or 2420×1668 on the 11-inch, so the Mac has a display whenever Mimac Connect is running. You do not need an HDMI dummy plug. If you have one from a previous setup, remove it: it gives the Mac a second, differently sized display that only gets in the way.

  8. Optional: add Tailscale for use away from home.

    On your own network you are done. To reach the Mac from anywhere, install Tailscale on both devices and connect by the Mac's Tailscale name. The Tailscale guide walks through it, including the key-expiry setting that matters for a Mac nobody sits at.

Living with it

Open Mimac, tap the Mac, and the desktop is there in a second or two. The first connection after installing can take longer while macOS prepares screen capture; every one after that is quick. Option+Tab opens the Mac's app switcher; Command+Tab stays the iPad's. Two-finger scrolling coasts like a MacBook trackpad, pinch zooms, and every Mac keyboard shortcut goes to the Mac. Audio comes through losslessly, and if you installed Mimac Microphone, your voice goes the other way.

To restart the Mac, use the Apple menu as you normally would. With Start before login installed, wait half a minute, reconnect, and log in at the login window from the iPad. After a macOS update, check that Screen Recording and Accessibility are still granted; macOS occasionally resets them, and this is what the Screen Sharing fallback from step one is for.

If pinch stops working after a macOS update, open Mimac's tuning panel and switch Pinch delivery to Control+scroll. Mimac Connect updates itself, and a fix for a changed macOS interface arrives that way.
